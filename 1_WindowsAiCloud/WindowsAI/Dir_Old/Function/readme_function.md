# Tips

    能用Ctrl+V就不要用输入法输入
        pyperclip.copy(exe_name)
        pyautogui.hotkey('ctrl', 'v')

    双下划线开头表私有函数/变量

    能不能OCR实时识别，就不保存了，因为已经有独立的录屏了——不行，OCR不能实时识别，必须保存

    了解Windows系统快捷键——https://baike.baidu.com/item/Windows%E5%BF%AB%E6%8D%B7%E9%94%AE%E5%A4%A7%E5%85%A8/407192
    Win+Up 最大化窗口
    Win+Home 最小化除当前活动窗口外的所有窗口
    Win+数字 打开任务栏中由数字代表的位置 Win+T 同理
    Win+B 打开右下角任务栏
    Win+D 显示桌面 Win+M 最小化所有窗口
    Win+E 打开资源管理器
    Win+I 打开设置
    Win+X 高级设置选项
    Win+A 操作中心
    Alt+Tab切换程序(加Shift反向)
    Win+Q 打开搜索框

    结束问题 即编码问题——为什么有时候有问题有时候正常
