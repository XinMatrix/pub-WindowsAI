# Sample_YOLOv8

Sample_YOLOv8 是一个基于 YOLOv8 的目标检测模型训练代码，可以用于训练自己的目标检测模型。
此外，Yolo还提供了其他检测模型，如 YOLOv8n-seg、YOLOv8n-cls、YOLOv8n-pose、YOLOv8n-obb

# 文件说明

- `train.py`：训练模型代码
- `process_images.py`：测试模型效果代码
- `yolov8x.pt`：默认模型权重文件
- `README.md`：说明文档
